# 家有备｜家庭安全协同 AI Agent

家有备是一套可演示的家庭安全协作应用，支持家庭记录持久化与本机视觉监测：

> 事件识别 → 情况理解 → 任务拆解 → 家庭协同 → 权限判断 → 人工确认 → 状态回传 → 审计留痕

核心边界：**AI 负责理解与规划，规则负责边界，人工负责关键确认。**

## 技术栈

仓库原有技术栈为 Next.js 16 + React 19 + TypeScript + vinext/Vite，因此本次保留并扩展现有架构，没有迁移到 Vue，也没有破坏原有 Cloudflare D1、Agent、工具注册中心和 Home Assistant 适配代码。

- Next.js 16 / React 19 / TypeScript
- vinext + Vite 8
- Lucide React
- 集中式 `useSyncExternalStore` 产品状态
- Mock / Real API Adapter
- Playwright Core + 本机 Chrome 端到端自测

## Mock / Real API 切换

复制 `.env.example` 为 `.env`：

```dotenv
VITE_USE_MOCK=true
VITE_API_BASE_URL=
```

- `VITE_USE_MOCK=true`：完整演示模式，不需要真实 FastAPI、模型或设备。
- `VITE_USE_MOCK=false`：启动时请求 `VITE_API_BASE_URL/api/bootstrap`；各领域 API 位于 `src/api/`。
- 页面只依赖产品 Store；切换后端不需要修改页面组件。
- 真实 API 不可用时，界面显示可恢复的错误状态，不会执行外部动作。

- `src/api/familyApi.ts`
- `src/api/eventApi.ts`
- `src/api/taskApi.ts`
- `src/api/deviceApi.ts`

## 核心 Demo

### 疑似摔倒视觉检测

在 Windows 上可直接双击仓库根目录的 `启动视觉检测.cmd`；保持弹出的命令窗口打开，脚本会等待服务就绪并打开 `http://localhost:3000/cv`。关闭命令窗口会停止本地服务。

1. 打开 `/cv`，主动选择本机摄像头或一个已获使用许可的本地视频。摄像头需要 `localhost` 或 HTTPS；页面必须保持打开才能持续监测。
2. 等待本地 MediaPipe Pose Landmarker 模型加载。页面显示骨架、画面躯干倾角、髋部下降比例和相对 3D 躯干角度。
3. 站立或坐直约 0.8 秒建立基准。新版 `torso-relative-v2` 以基准躯干长度归一化：近期直立后倾斜至少 55°、髋部下降至少 0.6 倍、肩部下降至少 0.5 倍，持续低位至少 0.6 秒时，创建**疑似摔倒**事件、人工核实任务、站内通知和审计记录。遮挡、多人或时间中断会清除连续证据。
4. 点击“查看事件”，通过关联任务联系本人并记录核实结果。模型不会自动呼叫救援或控制门锁。

姿态推理在浏览器内运行，原始画面和关键点不上传。真实 API 模式上报输入类型、画面倾角与下降、相对躯干下降倍数、持续时间和规则版本，写入当前家庭的事件/任务/通知/审计；同一家庭同类来源 60 秒内重复触发会合并。此本机主动授权与示例家庭中始终拒绝的 **D006 客厅摄像头** 规则是两种不同的数据源，不会读取 D006。

模型包与 WASM 放在 `public/cv/`，首次加载后不依赖第三方 CDN。模型来自 [MediaPipe Pose Landmarker Lite](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker)；`@mediapipe/tasks-vision` 使用 Apache-2.0 许可。

2026-10-28 已对 URFD 的 32 段公开实验视频进行两模型、两批次探索检查，结果保存在 `public/evidence/`。新版 Lite 第一批检出 2/8、第二批 3/8；各批日常动作误触发 0/8。仍有明显漏检，未按受试者隔离，不构成真实家庭可靠性结论，不能作为独立的生命安全报警器。相对 3D 关键点可旋转查看，但不参与告警，也不是房间绝对高度；没有引入额外完整 Human3D Motion 模型。

视觉页现在提供 Lite 默认 / Full 对照、两个已获许可的内置实验片段、骨架隐私显示、条件解释与运行 JSON 导出。正常播放结束保留最后一次已分析姿态，暂停或拖动仍会重置判定。导出保留最近 3,600 帧数值与 120 条状态变化，不包含原始关键点或视频；推理耗时不含解码和网络。

### 陌生人请求开门

1. 打开 `/demo`，触发“陌生人请求开门”。
2. 系统先由安全规则拦截门锁，进入授权确认弹窗。
3. 查看 AI 意图、原因、设备和可能后果。
4. 选择“拒绝”。授权决定与拦截记录保存，门锁不执行；关联核实任务仍需人工处理。
5. `/audit` 中记录拒绝原因和 `blocked` 结果。

## 当前能力与后续验证

仓库已经提供家庭记录、任务、授权、成员、服务资源、记忆和工具记录的 D1 接口。使用同源服务端时设置 `VITE_USE_MOCK=false`，并保持 `VITE_API_BASE_URL` 为空。前端配置修改后需重新启动或构建。

- 默认演示模式使用示例家庭；新增与处理结果保存在当前页面会话，整页刷新恢复初始状态。
- 服务端 `AUTH_MODE=demo` 为单家庭开发演示；`AUTH_MODE=real` 检查登录会话，并需配置认证密钥。
- 任务必须先保存核实记录，再确认完成；确认时间由服务端生成。
- 页面可见时每 30 秒检查家人的最新记录，切回页面或恢复联网也会检查。更新不会清空输入或中断视觉监测；任务发生版本变化时，需核对最新记录后再保存草稿。
- 家庭接口禁止保存 HTTP 缓存，登录状态与家庭记录按当前会话重新获取。
- 更新失败会保留上次加载的内容并明确提示。页面提供“更新记录”入口；账号会话失效时会清除已加载数据并返回登录。
- 未提交的任务草稿暂存在当前标签页，刷新可恢复；按账号、家庭和任务分开保存，24 小时后过期，退出或会话失效时清除。草稿未提交前不会发送给家人。
- 保存接口返回需要登录时会清除已加载记录。退出或切换账号后，旧请求的成功或失败结果不会继续更新新账号的数据、对话或保存状态。
- 同一浏览器的标签页同步登录与退出；另一页更换账号后，旧家庭记录和未提交草稿清除，并重新检查当前账号。页面从浏览器保存的状态恢复时也重新检查。
- AI 请求没有收到完整响应时，页面会提示先核对最新事件和任务，再决定是否重试；关闭提示不代表已经改变服务端模型配置。
- 已过截止时间的未完成任务会显示超时提示，执行状态保持原样；这不代表后台已经发送催办或安排自动升级。
- 演示家庭使用固定场景快照与预设任务状态，超时不随实际日期推进；真实数据适配器按实际截止时间显示。
- 任务页支持直接创建任务，填写负责人、优先级、期限和来源事件；关联事件与操作记录一起保存。
- 请求帮助会保存关联任务的站内提醒，“需要协助”分类可直接查看。家人接手后更新为当前账号对应的负责人，转交或完成时清除求助标记；这不代表已经向外部渠道发送消息。
- 授权决定只保存一次，并更新事件与审计。保存授权决定不会自动操作受保护设备。
- 门锁与摄像头直接执行接口受保护；真实设备当前只支持已映射的灯光开启。
- 新增服务资源需要填写联系方式，标记为已核实前需保存核实方式与结果。
- 设置页的更大文字与减少动画偏好保存在当前浏览器。
- 手机表单使用 16 像素文字；长弹窗可以内部滚动。较大文字偏好也应用于登录和邀请页。320 像素宽与短窗口已检查，实际手机键盘和 Safari 仍需单独验证。
- 浏览器图标、手机主屏幕图标和界面标志统一。PNG 图标可用 `node scripts/generate-app-icons.mjs` 从 SVG 重新生成；实际手机安装体验尚需在设备上检查。
- 过长的标题和说明先显示摘要，可展开完整内容。聊天阅读区域有高度限制；查看旧消息时，新回复不会强制跳到末尾，可手动返回最新消息。
- 语音识别文字追加到现有输入，超长结果保留原草稿；权限失败、识别结束超时和离开页面会释放识别会话。浏览器接口模拟仅验证交互，不代表语音准确率。
- 管理员可编辑家庭名称与地址。准备指南显示实际家庭记录，并连接到对应管理页面。
- 真实认证模式支持成员邀请：管理员在成员详情指定邮箱，生成有效 24 小时的一次性链接，亲自转交家人。家人使用指定邮箱和自己的密码建立普通成员账号。系统不会代发邮件。
- 邀请可以撤销或重新生成，旧链接随即失效；同一链接只能成功加入一次。登录中的账号需先退出才能接受邀请，成员资料角色不会改变账号权限。
- 邀请提交时离开页面会中止浏览器请求，迟到的响应不会触发页面跳转。服务端可能已经建立账号，遇到无法确认的提交可用刚设置的邮箱和密码尝试登录。
- 管理员可以确认停止普通成员的账号访问，撤销其旧会话和通知订阅；保留成员资料、任务和已有记录。管理员账号受保护。需要重新加入时，可重新邀请并使用原邮箱。
- 真实账号可在设置页验证当前密码后修改登录密码，撤销旧登录会话和通知订阅，并保留操作记录。当前浏览器获得新会话；其他设备需重新登录，需要浏览器提醒时重新开启订阅。
- 修改已关联成员的称呼或电话会同步到其账号资料，账号权限保持不变。
- 图片附件与无来源趋势图已移除；语音输入依赖浏览器实际识别能力。
- 后台定时任务尚未启用，工具接口会明确返回未安排。
- 问候及完整的功能咨询不会创建应急事件；附加现场情况仍进入分析。模型引用的成员需要与家庭资料匹配。设备单次无人信号不能证明长时间无人，药盒开盒也不能证明服药。

尚需实际验证：按受试者隔离的独立视频评测、真实家庭场景、跨浏览器性能、真实设备接入、外部通知送达和部署后的认证配置。现有公开实验片段结果不等于家庭环境准确率；没有通知送达率结论。

视觉推理优先在后台线程运行。暂停、拖动视频、长时间丢帧、画面尺寸变化或多人入镜会中断轨迹，需要重新建立基准。视频回放与摄像头疑似事件分别标识。

导出含家庭地址、联系方式和协作记录，请妥善保管。文件不含登录凭据和摄像头画面。更多改进与验证范围见 [项目质量路线](docs/项目质量路线.md)。
真实模式的审计 CSV 由服务端按当前家庭和所选筛选生成，仅管理员可批量导出；生成动作写入 D1 审计。文件生成不等于用户已经将文件保存到磁盘。设置页的 JSON 导出包含当前已加载的记录。
审计页面显示当前对象名称，并连接到对应任务、事件、成员或设备。原始对象字段保留在记录与导出中，可在名称提示中核对。
使用云端模型时，服务端会发送情况描述和相关家庭资料至配置的模型服务。摄像头原始画面始终在本机处理。
现场展示可按 [答辩现场演示](docs/答辩现场演示.md) 的约 7 分钟流程操作。
视觉模块已完成上述公开片段探索；后续按 [视觉评测方案](docs/视觉评测方案.md) 补充逐帧标注、受试者分组、独立测试和 2D/3D 对照。严格独立评测尚未完成。

原有 Agent、D1 记忆、工具注册中心和 Home Assistant 代码继续保留在 `lib/`、`db/` 与现有 `/api/*` 中。

`drizzle/0002_family_scope.sql` 补齐历史迁移中缺失的家庭归属、设备映射和认证字段。服务端会检查并补齐这些字段；已经由服务端补齐的数据库不要再次直接执行相同的 `ADD COLUMN`。本轮没有修改线上数据库或部署。
`0003_task_version.sql` 增加任务版本，避免并发确认与旧记录覆盖；服务端同样会检查补齐。
`0004_family_invitations.sql` 增加邀请与成员账号关联，并为已注册邮箱和账号关联建立唯一约束。邀请秘密只保存摘要，列表不返回秘密；邀请链接在浏览器片段中携带令牌，加入成功后清除。
`0005_task_notifications.sql` 增加通知关联任务的字段。服务端检查补齐，历史通知继续可读。
`0006_notification_reads.sql` 保存真实账号各自的通知已读记录。一个家人查看提醒不会替其他家人标记已读；已处理事项不再提示未读，历史记录保留。通知页可筛选未读。

浏览器通知在设置页主动开启或关闭。订阅保存不等于已经送达；需要服务端配置 VAPID、浏览器许可和实际网络验证。服务端按当前账号保存和删除订阅，退出会撤销该账号的旧会话与订阅。

推送服务地址范围参考浏览器服务的官方说明：[Chromium](https://chromium.googlesource.com/chromium/src/+/refs/tags/148.0.7734.4/components/push_messaging/push_messaging_constants.cc)、[Mozilla](https://mozilla-services.github.io/autopush-rs/http.html)、[Apple](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers)。其他服务地址需由开发者核实后加入支持范围。

真实适配器保存验证需另开本地服务（不修改 `.env` 文件）：

```powershell
$env:VITE_USE_MOCK='false'
$env:VITE_API_BASE_URL=''
npm run dev -- --port 3012
```

然后在另一终端运行 `npm run test:save:real`。该检查使用专用本地记录并在结束时清理；不会验证外部通知送达。
`npm run test:invite:e2e` 使用同一个 3012 页面，但所有应用接口都转到独立临时 Worker/D1 环境，验证管理员与手机尺寸家人的两个会话、网络失败重试和账号访问停止，不向真实联系人发送消息。
`npm run test:session:real` 同样使用隔离环境，验证任务保存遇到未登录、通知与 AI 迟到结果、视觉摘要上报和资料保存结束时切换账号，不污染下一账号或清除其新请求的忙碌状态。

本地开启真正的登录和邀请，需要前端 `.env` 中 `VITE_USE_MOCK=false`；服务端设 `AUTH_MODE=real` 和随机 `AUTH_SECRET`。可以复制 `.dev.vars.example` 为 `.dev.vars` 后填写服务端配置。如果已有 `.dev.vars`，请在该文件维护服务端配置，避免与 `.env` 重复定义。更改后重新启动服务。线上密钥通过 Worker secrets 配置，不放进前端变量或版本库。
