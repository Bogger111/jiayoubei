# 家有备 · 演示启动指南

## 最快上台方式

1. 将整个 `deliverables` 文件夹复制到比赛电脑，保留目录结构。
2. 用 Microsoft PowerPoint 打开 `家有备_创客大赛_终版.pptx`，按 F5 放映。
3. 到第 9 页点击画面播放内嵌录像，或点击“打开离线 Demo”。
4. 演示结束回到第 10 页继续。建议全程约 6 分半。

本包含 14 页原生 PowerPoint、同版 PDF、约 60 秒 MP4、15 张产品截图、离线 Demo 和备查材料。PDF 用于静态放映，视频另外播放；PPTX 内已经嵌入视频。

## 不开终端也能运行

直接双击 `启动演示.cmd`，或进入 `demo` 文件夹，用 Chrome / Edge 打开 `index.html`。无需安装软件包、启动服务器或连接网络。点击右上角“重新开始”即可恢复初始状态。浏览器 F11 可以全屏；投影建议 1920×1080 或 1600×1080，浏览器缩放 80%–100%。

## 完整操作顺序

开始异常协作演示 → 等待约 4 秒形成计划 → 子女同意并开始安排 → 切换为联系人 → 接手本次联系 → 暂未联系到继续跟进 → 勾选已核实 → 记录明确结果 → 查看全过程记录。

高风险备用场景：页面底部“体验高风险授权场景” → 开始 → 屋主核实后保持关闭。该演示不向门锁发送指令。

## 三种放映保障

- 首选：PowerPoint 第 9 页播放内嵌视频，连续展示完整操作。
- 现场互动：双击离线 Demo，无需网络；所有关键按钮可操作，事件保存在本地浏览器。
- 静态备用：打开 PDF，单独用系统播放器播放 `demo.mp4`。

## 从项目打开

原应用启动后打开 `http://localhost:3000/showcase`，也可从“更多功能”进入“比赛核心演示”。原多模态体验仍为 `/experience`，原关怀工作台仍为 `/care`。独立离线文件适合直接上台，原后端账号协作适合技术答问。

## 开发复现

在项目目录依次运行：

```text
npm run showcase:build
npm run showcase:prove
npm run deck:final
powershell -File scripts/competition/export-final-powerpoint.ps1
```

`showcase:prove` 会写入原始 WebM；MP4 由 ffmpeg 转码后，再生成 PPTX。PPTX 生成使用 PptxGenJS；PDF 与逐页图片通过本机 PowerPoint 导出。演示脚本默认本机 Chrome 路径，重录时需 Node.js、依赖与 Chrome。普通放映不需要这些开发工具。

模型原始输出、构造家庭输入与操作结果分别记录：关键点回放来自本次本地姿态模型运行，规则现场执行；家庭与角色为演示场景，设备动作与联系采用本地模拟。实际 ESP32、实时语音及外部消息未在本次联调。来源与许可统一保存在 `开源组件与许可证.md` 和根目录 `appendix.md`。
