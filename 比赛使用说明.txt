二、讲述主线
家有备是多模态家庭协作 Agent。首先服务子女与父母分居的家庭，帮助他们在异常联系不上时，把关心落实为安排。
从“妈妈怎么还没回应”进入：汇合活动、门磁、语音回应与授权图像，整理一份完整计划，家人批准后协同执行，跟进到回应。
商业方案是子女按家庭订阅，接入兼容已有设备。试用、定价、渠道合作与用户认可需要通过后续真实使用验证；不要将计划人数说成已有用户。
视觉检测保留为一个可选感知模块，主讲不需要展开模型或摔倒片段。

三、两分钟演示顺序（第 13 页）
0:00–0:25：选择未回应情景，讲解设备与回应记录如何合在一起。
0:25–0:50：查看计划，点击“同意并开始安排”，展示设备步骤与家庭联系任务。
0:50–1:10：点击“收到平安回应”，观察后续联系停止，避免继续打扰。
1:10–1:35：切换外出情景，展示程序给出的不同安排；切换授权图像情景，展示画面证据。
1:35–2:00：播放“实际操作录屏”，说明应用中的计划编辑、任务和时间线都可实际操作。
如需演示超时：重新开始 → 同意 → 推进至等待结束。这个按钮只推进 PPT 情景时间，应用按计划等待实际时间。

四、打开应用
在项目目录执行 npm run dev -- --port 3000，打开 http://localhost:3000/。
首页可调整联系人与等待时间、批准计划、记录家人回应、查看事件进度。设备依据和授权图像在“查看依据”中查看。
顶部“家庭 / 行动 / 设备 / 记忆”为常用入口；“更多功能”提供家庭事件、成员、联系人、授权、审计、视觉模块和比赛演示。
Ctrl/Cmd + K 搜索事件、任务、家人和设备。手机端使用右上角菜单。
默认演示家庭的更改保存在当前页面会话，刷新恢复。真实 API 模式沿用已有家庭记录接口；新版情景编排的执行入口目前限演示模式。
