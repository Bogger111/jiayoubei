# 家有备前端设计系统

本轮以家庭协作助手为产品中心。保留 React 19、现有共享组件、路由、家庭权限与 API，不迁移框架。助手、空间、设备、记忆和行动使用同一套视觉语言。既有竞赛离线演示作为独立交付保留。

## 方向与取舍

采用品牌标志中的松绿色、清晰的中文排版和接近真实居家材料的安静底色。助手的大对话框与三维家庭空间是视觉重心。其余页面以内容和可操作状态组织信息，减少解释性卡片、装饰标签和低对比度文字。

比较过全屏侧栏式聊天与共享顶部导航式工作区。选择后者：用户在对话中安排事务，也能随时检查家庭、空间、行动、设备和记忆。避免把商业产品做成单独的聊天演示。

## 基础规范

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 纸白 | `#F7F8F5` | 页面底色 |
| 白 | `#FFFFFF` | 主要工作区 |
| 松绿 | `#214D43` | 主操作、选中、品牌 |
| 石墨 | `#202C27` | 正文、标题 |
| 灰绿 | `#5F7067` | 次级内容，保证可读性 |
| 鼠尾草 | `#EAF0EA` | 选中底色、辅助状态 |

边线 `#DBE3DC`；成功、警告、危险使用独立语义颜色。保留三维渲染器的深色舞台和扫描坐标色，避免用全局颜色影响实际模型。

文字以 Segoe UI Variable Text / Segoe UI 与 Microsoft YaHei UI 为明确系统字族，iOS 使用 PingFang SC。无需下载字体即可离线运行。标题 28–38px，正文 15–16px，辅助内容 12–14px。中文行高 1.7，长段落约 65 字以内。数值使用等宽数字。

间距使用 4、8、12、16、24、32、48、64px。控件圆角 10px，分组面板 16px，主要对话容器 24px；不将所有元素做成同一种圆角。仅对浮层和输入焦点使用明显阴影。

按钮最小高度 42px，手机主要点击区域 44px；图标按钮有可访问名称。主要动作使用深绿实底，次要动作白底边线，文字动作不额外套卡片。表单统一标签、输入、帮助、错误和禁用状态。

## 各页面

- 助手：一个主要对话画布。消息保持清晰阅读宽度，真实结果卡使用记忆、计划和模型各自的结构；输入区固定在容器底部。
- 家庭与空间：真实三维模型占据主视觉，标题与操作保持简洁；家庭事务用连续列表承接。
- 设备：先看连接与房间，再看设备状态；部署引导缩成步骤行，控制区与设备清单形成明确层级。设备是可操作对象，可使用有边界的分组，但不重复套背景面板。
- 记忆：有记录时用时间线与来源预览；空状态保留一个明确入口，不凭空填充内容。检索区与正文有清楚区分。
- 行动与其他页面：统一标题、列表、筛选、状态标签、详情和弹窗。颜色表达状态而不是装饰。

桌面保持顶部导航，平板和手机将六个入口排到第二行并保持可见。布局按内容使用 1120、960、720、440px 断点，手机正文输入不小于 16px，避免系统自动放大。

过渡主要响应用户动作：按钮与焦点 140ms，展开与弹窗 180ms，结果出现 220ms。不自动循环装饰，不逐张卡片漂入。尊重 `prefers-reduced-motion`。

## 实现与检查

`app/design-system.css` 是设计 token 与共享组件规范；`app/assistant-home.css` 为助手布局；既有 `family-design.css` 保留工作台结构并迁移至语义颜色。所有业务接口与执行确认流程保持原有服务。

以实际 Chrome 页面检查桌面和手机的布局、溢出、文字对比度、键盘焦点、表单和弹窗。用现有隔离浏览器流程回归照片建模、记忆、设备部署、批准回执与对话历史，真实模型调用证据单独保留。
