## 我们的定位判断

家有备的首发重点是：汇合经授权的家庭线索 → 整理完整计划 → 家人批准 → 联系人明确接手 → 依结果继续或结束。长期仍为家庭协作 Agent，异地照护是首发场景。

这是团队选择聚焦的体验，并非“竞品全都没有协作”或“国内首创”的事实断言。类似产品已经存在，说明可参考的产品形态与技术路径；它们不能直接证明家有备的需求规模、付费意愿或商业成功。

人口背景采用[国家统计局 2025 年统计公报](https://www.stats.gov.cn/sj/zxfb/202602/t20260228_1962662.html)：60 岁及以上 32338 万人，占 23.0%。该数不是付费用户规模。家庭订阅、招募渠道和试用目标均为待验证方案。

## 本轮 PPT 调整

1. 开场使用家庭情景和短句，让观众先看到具体的协调困难。
2. 第 4 页加入三个同类方向与家有备切入点，来源在答问附页可点击。
3. 放大现有程序截图；柔和边框、淡玻璃和蓝色主操作保留，减少密集文字列表。
4. 技术页讲时间与权限、家庭约定、明确接手与结果，细节放讲稿。
5. 运行证据页读取同一事件的实际 API 轨迹，配实际联系人端局部截图；五种情景移至可展开的运行记录。
6. 保留双账号操作录屏、软件演练来源标签和完整离线能力。

## 当前展示可支持的结论

当前可展示：在构造输入和独立测试账号下，软件能生成安排、绑定版本批准、接手、保持未联系到状态、明确核实后结束，并恢复持久化记录。测试账号不代表真实用户；电话结果备注不代表实际电话呼叫。

实际 HA/ESP32 物理链路、真实家庭演练、自然使用和付费意愿仍需采集。相关操作包在 `docs/care-p0/`，本轮不增加额外模型或伪造用户结果。
