# 记忆编辑与房间实测

## 使用入口

- `http://localhost:3000/memory`：家庭动态选择一条记录，点击“编辑记忆”；可修改标题、内容、房间，也可更换照片。没有选择新照片时保留原图。
- 同页“习惯与约定”：点击对应条目的“编辑”，修改后保存。两类修改都保存到当前家庭的数据库，刷新仍可读取。
- 记忆维护由家庭管理员操作。每次编辑检查读取时的内容或版本，发现别人已修改时提示刷新，不覆盖更新。
- `http://localhost:3000/create-space?id=p_a847d7ccf6aa4713b658021f01b5fe2b`：本次实际生成的起居室草稿。点击“微调家具”编辑；“保存并返回”或“保存草稿”保存草稿。确认“保存为家庭空间”才会替换当前家庭布局。
- 原有 `/space` 四房样例保留，包含 66 件家具。新草稿不会自动覆盖它。

## 本次运行结果

同一间起居室 6 张公开照片，经真实识图服务生成 1 个房间、20 件家具，生成服务返回 8.76 秒。随后实际打开原生编辑器，新增办公椅，保存并整页刷新后验证 21 件家具、草稿版本 2。它是按照片理解和家具库搭出的近似家居布局。

“试用样例照片”已换成这组六视角输入。照片来源、文件摘要和许可核查情况见 `appendix.md`。PPT 使用记忆界面截图，未使用这组照片。

记忆编辑在隔离演示家庭中检查：修改动态文本和房间，保留原照片；修改既有习惯，保持记录 ID 和数量；整页刷新；检索修改后的内容。现用家庭的记忆没有被测试数据填充。
