# 家有备比赛网站访问说明

比赛网站使用统一访问码。网站部署者在仅本人可访问的初始页面中自行设置访问码，再把访问码告诉评委；不要把访问码或模型密钥提交到仓库。

- 访问码需为 12—128 位英文字母、数字或符号。服务器只保存加盐后的摘要，不保存明文；有效会话最长 8 小时。
- 连续输错 8 次后，来自同一来源的访问会暂时受限。公网入口启用前必须先完成访问码设置，且将 `PUBLIC_DEMO_MODE` 从 `bootstrap` 调整为 `enabled` 并重新部署。
- `PUBLIC_DEMO_SIGNING_KEY` 必须通过网站平台的运行时密钥配置，不能写入源代码。只有站点处于本人私有状态时才可使用 `bootstrap` 模式。
- 公网演示里的所有持码访客共享同一个示例家庭，可以读取和修改彼此录入的记忆、照片、对话及空间。不要在演示网站输入私密家庭资料；它不是多人数据隔离的正式产品。
- 当前托管平台会直接公开部分打包的静态图片和展示页面；访问码保护应用页面与数据接口，不能把保密文件放进 `public/`。
- 当前设备是软件样例，AI 和照片建模依赖这台电脑的本机服务与临时连接。电脑、服务或连接中断后需要重新连接。GitHub 更新不会自动发布到网站。
- 若要更换访问码，先将网站恢复为仅本人访问，再处理访问码设置；不要在公开状态下开启首次设置。

开发验证：`npm run test:demo:access` 在隔离数据库中验证首次设置、摘要保存、错误码限速、会话和公开模式。该测试不会修改现有家庭数据。
