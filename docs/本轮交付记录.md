# 本轮交付记录

最近核验：2026-10-12。修改保存在当前工作目录，尚未提交或部署。

## 打开应用

双击项目根目录的 `启动视觉检测.cmd`，保持服务窗口打开。

- 家庭总览：<http://localhost:3000/>
- 视觉监测：<http://localhost:3000/cv>
- 答辩场景：<http://localhost:3000/demo>

最后检查三个入口均返回正常页面。默认示例家庭适合现场展示；真实账号能力需启用真实适配器与认证配置，见 README。

- 最新类型检查、代码检查、生产构建和本地生产启动通过。
- 45 项基础检查通过，包含规则、数据库迁移、数据格式与源文件约束；源文件约束不等于实际功能运行。

- 工作目录差异格式检查通过。
