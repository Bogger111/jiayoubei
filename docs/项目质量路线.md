# 家有备项目质量路线

目标：简约、清晰、可信，能够在答辩现场演示，也能够由家人理解和使用。

## 持续工作顺序

1. 运行与入口：可重复启动；统一演示入口；直接刷新详情页仍然可用。
2. 安全协作：家庭数据范围、服务端授权、保存失败反馈、真实处理记录与完成确认。
3. 视觉监测：固定画面校准、正确的时间与画面比例、遮挡与暂停处理、输入类型标识、资源释放。
4. 界面：统一字号、色彩、间距与按钮；突出当前重要事项；手机与键盘完整可用。
5. 工程：拆分组件；移除误导性的占位能力；可复现的流程测试与生产构建。
6. 展示：展示已实现流程，标清模拟输入与原型限制；指标需要原始记录支持。

- 账号管理的隔离接口验证通过：管理员保护、并发停止只记录一次、旧密码和会话失效、订阅撤销、原资料和任务保留，以及原邮箱重新加入与登录。

- 多标签页验证登录和退出同步：浏览器消息通道、存储事件回退和两者同时启用均通过；另一页退出会清除家庭记录与草稿，重新登录显示正确家庭。浏览器恢复事件的处理已检查，未声称覆盖所有浏览器的实际页面缓存行为。
- 邀请提交后离开页面中止浏览器请求，迟到响应不改变当前页面；服务端已经建立的账号可以通过正常登录恢复。
- 自助更新密码通过隔离接口与页面验证：当前密码核验、输入范围、并发唯一成功与审计留痕、旧密码/会话/订阅失效、当前浏览器新会话有效，以及其他家人账号和订阅保持可用。

- 过长标题与说明可展开全文。聊天验证覆盖长文字、最新回复滚动、阅读旧消息时保持位置、返回最新和新对话重置。
